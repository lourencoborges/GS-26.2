MLAM — MACHINE LEARNING E ANÁLISE DE MOBILIDADE
============================================================
Projeto: análise estatística de dados reais de compartilhamento de bicicletas, aplicada à mobilidade urbana.

O QUE ENTREGAR NO PORTAL
Um representante do grupo deve enviar diretamente no Portal, sem substituir os arquivos por links:
- Base de dados no formato .csv ou .xlsx.
- Código Python no formato .py.
- Relatório estatístico no formato .pdf.

O trabalho deve incluir:
1. Probabilidades sob a hipótese de distribuição normal para uma variável numérica: P(X < média) e P(X > mediana), com classificação dos eventos.
2. Dois testes de hipótese unilaterais para a média: n=20, α=6%, alternativa média menor; e n=25, α=9%, alternativa média maior. Usar como referência o desvio padrão populacional dos dados.
3. Análise bivariada de duas variáveis quantitativas: dispersão interpretada, covariância, correlação de Pearson, gráfico de correlação, regressão linear simples, equação, R², teste F, interpretação e previsão.
4. Análise multivariada linear com pelo menos três variáveis quantitativas: dispersão, matrizes de covariância e correlação, gráfico de correlação, interpretações, equação de regressão múltipla, R², teste F e previsão usando pelo menos duas variáveis explicativas.
5. Análise multivariada logística binária com pelo menos três variáveis quantitativas: equação, matriz de confusão, acurácia com interpretação e classificação usando pelo menos duas variáveis explicativas.
6. Relatório profissional em PDF com tabelas, gráficos, medidas estatísticas e interpretações, extraindo insights úteis para o problema de mobilidade.

ARQUIVOS JÁ DISPONÍVEIS
- Base CSV: MLAM/arquivo_analise_mobilidade/dados/bike_sharing_hour.csv.
- Código: MLAM/arquivo_analise_mobilidade/codigo/analise.py.
- Relatório editável: MLAM/arquivo_analise_mobilidade/relatorio_estatistico.docx.
- Resultados e gráficos: resultados.json e pasta figuras/.

PENDÊNCIAS PARA FECHAR A ENTREGA
- Exportar o relatório DOCX para PDF e conferir o PDF final.
- Conferir se o CSV, o .py e o PDF são os arquivos finais corretos e enviá-los no Portal nos formatos exigidos.
- Incluir nome completo e número de matrícula de todos os integrantes nos materiais/relatório.
- Conferir as instruções específicas e formatação ensinadas pelo(a) professor(a); a orientação geral alerta que os arquivos efetivamente enviados serão avaliados, sem substituição após o prazo.

O código disponível já contém blocos para probabilidades e testes de hipótese, análise bivariada com regressão simples, análise multivariada linear e logística, além da geração do relatório Word. Portanto, o principal ajuste de formato identificado é gerar e revisar a versão PDF do relatório.
